# Karbexa Admin web app

React + Vite + TypeScript + Tailwind. Org administration, plus the operator console at `/operator`.

See the repository [README](../README.md), [AGENTS.md](../AGENTS.md) and [DESIGN.md](../DESIGN.md).

```bash
npm ci
npm run dev        # http://admin.karbexa.localhost:5173
npm run build      # type-check + production build into dist/
```

Build-time settings (`VITE_*`): see `.env.example` and `../docs/CONFIGURATION.md`.
